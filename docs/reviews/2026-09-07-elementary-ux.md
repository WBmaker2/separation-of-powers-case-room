# 초등학생 UX 개선 기록 — 2026-09-07

초등 5–6학년을 대상으로 하는 삼권분립 사건 처리실을 학생 관점에서 모의 점검한 뒤 개선했습니다. 실제 학생 연구나 VoiceOver 인증은 아닙니다.

## 개선

- 단계 전환 때 현재 상태/제목으로 키보드 포커스 이동
- 선택 안내가 상단 메뉴·하단 진행표에 가리지 않도록 스크롤
- 분기·결과·참여자·헌법재판소 안내 문구 명료화
- 효력·행정소송·소장·거부처분 풀이 추가
- 활성 주요 버튼 아우라와 움직임 감소 설정의 정적 대안
- 정보 창 제목 ID 고유화, 최종 자기 설명 과제와 업데이트 내역 추가

## 검증

단위 13개, 렌더링 2개, lint, Pages build 통과. 최종 정적 번들에서 320px 키보드 전체 학습 완료와 피드백 가시성을 확인했습니다. 375/1280px 전체 흐름, 양쪽 법률안 결말, 오답/잘못된 예측 뒤 회복, 직전 단계 복원, 다시 시작, 대화상자 Escape·포커스 복귀를 확인했습니다. 관찰된 가로 넘침과 실행 오류는 없었습니다. 앱 코드/CSS는 파일당 500줄 미만입니다.

[320px 개선 화면](../../artifacts/qa/2026-09-07-feedback-320.png)

기관 역할과 법률적 상태 전이, 정답 위치 4/4/4, 밝은 테마, 개인정보 미수집과 비경쟁 학습 계약을 유지했습니다. 새 의존성·새 이미지·새 시뮬레이션·음성 기능을 추가하지 않았습니다.

커밋·푸시·배포는 수행하지 않았습니다. [현재 공개판](https://wbmaker2.github.io/separation-of-powers-case-room/)에는 이번 수정이 아직 반영되지 않았습니다. [로컬 개선판](http://127.0.0.1:64173/separation-of-powers-case-room/)은 미리보기 서버가 실행 중인 이 컴퓨터에서 확인할 수 있습니다.

상세 계획, 감사 장부, 문구 전후 비교, 점수/미실행 범위는 로컬 work/elementary-webapp-ux-*.md에 보존했습니다. 실제 학생·교사 수업 검수 및 공개 릴리스는 별도 단계입니다.
